# mcp2518fd driver

mcp2518fd driver for the rp2350 to enable communication over CAN bus through SPI protocol

## Assumptions

I am writing this guide under the assumption that openocd and the pico environment are set up on your system. I am also assuming that you are using the two-pico setup, with a pico as a hardware debugger and a second pico as a target board.
